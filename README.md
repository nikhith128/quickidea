# Quickidea

A lightweight idea-capture app. Ideas are stored in your browser's local storage.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). Set `PORT` in `.env` to use
a different port. For development with automatic server restarts, run
`npm run dev`.
